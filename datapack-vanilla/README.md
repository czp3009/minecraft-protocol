# datapack-vanilla

Release-matched official data packs for [world-format](../world-format). `VanillaDataPacks` exposes raw
`DataPackArchive`
values, parsed `DataPack` values, the core stack, and built-in pack selection. Archives are loaded per pack on demand.

`WorldDataPackLoadResult.toVanillaDataPackStack()` completes a persisted world selection using bundled packs and the
file
packs already read by the caller. It preserves their priority and inserts the core pack when the selection omits it.

Configuration projection is a separate step provided
by [protocol-configuration-vanilla](../protocol-configuration-vanilla).
This module has no runtime dependency on protocol libraries. Official payloads and the data-pack format version are
generated by Gradle from the root extraction artifact for the repository-selected release.

To inspect a bundled pack with an explicit parser, obtain its ID from `VanillaDataPacks.dataPackIds`; this example uses
the core ID. The plain path exposes the raw archive before parsing:

```kotlin
val dataPackId = VanillaDataPacks.coreDataPackId
val dataPackArchive = VanillaDataPacks.dataPackArchive(dataPackId)
val dataPack = DataPackFormat().decode(dataPackArchive)
```

The convenience path is `VanillaDataPacks.parseDataPack(dataPackId, DataPackFormat())`. It also supplies the generated
core pack metadata when absent from the archive. Use `VanillaDataPacks.coreDataPack` to reuse the bundled default parse.
`DataPackFormat` lives in `com.hiczp.minecraft.world.format.datapack`.

For a stored world, obtain `worldDataPackLoadResult` from an open
`MinecraftWorldAccess.dataPacks.readEnabled()` in [world-io](../world-io/README.md#read-world-data-packs), then complete
the
selection in one call:

```kotlin
val dataPackStack = worldDataPackLoadResult.toVanillaDataPackStack()
```

Pass that stack to [Configuration projection](../protocol-configuration-vanilla/README.md#add-world-packs), or call
`dataPackStack.resolve(VanillaDataPacks.dataPackFormatVersion)` for a priority view of resources.
